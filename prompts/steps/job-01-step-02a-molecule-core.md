Build the molecular layer: everything that represents a chemical structure. Internal representation is RDKit; the RMG adjacency list is a serialization format. gates/gate_01.py over the test set (species from examples/rmg/ superminimal + c3h4 + minimal input.py + all entries of a small thermo library): 1. adjlist round-trip: parse(Molecule.to_adjlist()) == Molecule (RDKit isomorphism), and to_adjlist() functionally equivalent to RMG-Py's toAdjlist() (references generated by a small RMG-Py script into gates/baselines/adjlist/). 2. canonical SMILES == RDKit canonical (sanity). 3. isomorphism/substructure on a 20-pair set (incl. "same molecule, different atom order" + substructure-with-degeneracy): match RDKit direct calls (pins the wrapper API). 4. atom types: assign_atom_types() equals RMG-Py's assignment (references into gates/baselines/atomtypes/). 5. resonance sets: rmgpu resonance set == RMG-Py's (SMILES-set equality) for the test molecules.
